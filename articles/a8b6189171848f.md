## はじめに

吊り荷を目標とするYaw角へ自動的に旋回させる制御システムを開発しました。

最終的な目標は、カメラ画像から吊り荷のYaw角を推定し、その推定結果を用いて4基のスラスターを制御することです。制御モデルには強化学習を使用し、最終的にはRaspberry Pi上で画像認識と制御を組み合わせたリアルタイム制御を行います。

このシステムは、次の流れで段階的に構築しました。

## Blenderオブジェクトの構成

Blender上に、クレーン、スラスター機体、吊り荷を配置し、吊り荷の旋回をシミュレーションできる環境を構築しました。

![](/images/payload-yaw-control/01/crane.png)

シミュレーション環境は、主に以下のオブジェクトで構成しています。

- **クレーン**
  - 吊り荷を支持するクレーンモデル
  - クレーン先端からスラスター機体を吊り下げる

- **制御装置**
  - 吊り荷の上部に配置
  - 4基のスラスターを搭載
  - スラスターの推力によって機体および吊り荷をYaw方向に旋回させる

- **吊り荷**
  - H鋼（HSteel）
  - 平板（Plate）
  - トラス（Truss）

形状による制御特性の違いを確認するため、吊り荷は3種類用意しました。

### 制御装置

吊り荷の上部に、4基のスラスターを備えた制御装置を配置します。
![](/images/payload-yaw-control/01/thruster.png)


各スラスターの出力を組み合わせることで、時計回り（CW）または反時計回り（CCW）の回転力を発生させます。同じ回転方向となる対角位置の2基を組み合わせることで、Yaw方向の旋回を制御します。

![](/images/payload-yaw-control/01/thruster_forces_en.png)

図中の `[1,0,0,0]` などは、4基のスラスターへの出力指令を表しています。


### スラスター出力とYaw回転

各スラスターを単独で最大出力（250 N）とした場合の動作を確認します。対角位置のスラスターは、同じ回転方向のYawモーメントを発生させます。

@[youtube](TdAca_NXTxE)

強化学習による制御では、4基のスラスター出力を組み合わせることで、吊り荷を目標Yaw角へ旋回させます。

### クレーンとオブジェクトの位置関係

スラスター機体はクレーンからロープで吊り下げ、その下にさらに吊り荷を配置しています。

![](/images/payload-yaw-control/01/object_heights.png)


クレーンの旋回中心からスラスター機体までの距離は約 10.7m、スラスター機体から吊り荷までの距離は約 3.8m としました。

また、シミュレーションではクレーンを固定した状態だけでなく、クレーンを旋回させながら吊り荷のYaw角を制御します。クレーンは約50秒かけて90°旋回し、その後は停止した状態で60秒までシミュレーションを継続します。

## Blender Pythonスクリプト

### ロープを接続点に追従させる

使用するスクリプト：`blender/rope_attach.py`

クレーン、制御装置、吊り荷の間には、吊り下げ状態を視覚的に表現するためのロープオブジェクトを配置しています。オブジェクト間の物理的な位置関係や運動は、PyBullet を使用した物理シミュレーションで計算します。物理シミュレーションの設定については、別の記事で紹介します。

Blender 側では、物理シミュレーションによって変化する各接続点に、ロープの両端を追従させます。H鋼の場合の主な接続点を以下に示します。

![](/images/payload-yaw-control/01/rope-attachment-points.png)

ロープの接続関係は、ロープ名と両端のオブジェクト名の組として定義しています。

```python
ROPE_PAIRS = [
    ("Rope_CraneBoomL_HookL", "Crane_Boom_L", "Crane_Hook_L"),
    ("Rope_CraneBoomR_HookR", "Crane_Boom_R", "Crane_Hook_R"),

    ("Rope_HookB_THRTopL", "Crane_Hook_B", "THR_Top_L"),
    ("Rope_HookB_THRTopR", "Crane_Hook_B", "THR_Top_R"),

    # HSteel
    ("Rope_THRT_HSteel_Blue", "THR_Bottom_R", "HSteel_Cramp_Blue"),
    ("Rope_THRT_HSteel_Red",  "THR_Bottom_L", "HSteel_Cramp_Red"),
]
```

この接続情報をもとにロープオブジェクトを設定し、両端の接続位置に追従させます。

`register_ropes()` では、ロープを2点のPolylineとして初期化した後、`frame_change_pre` ハンドラに更新処理を登録します。これにより、シミュレーションの各フレームでロープの両端位置が更新されます。

```python
def register_ropes():
    # Curveを2点Polyline化
    for rope_name, _, _ in ROPE_PAIRS:
        rope = bpy.data.objects.get(rope_name)
        if rope is None:
            print(f"[Missing Rope] {rope_name}")
            continue
        ensure_polyline_curve(rope)

    # 初回更新
    update_all_ropes()

    # 既存ハンドラ削除
    bpy.app.handlers.frame_change_pre[:] = [
        h for h in bpy.app.handlers.frame_change_pre
        if h.__name__ != "update_all_ropes"
    ]

    # フレーム更新時に追従
    bpy.app.handlers.frame_change_pre.append(update_all_ropes)

    print("Rope registration completed.")
```

他の吊り荷（平板、トラス）も同様に設定します。

### シミュレーション結果をBlenderで再現する

使用するスクリプト：`blender/move.py`

PyBullet によるシミュレーションでは、クレーン、制御装置、吊り荷の位置・姿勢をフレームごとに CSV ファイルへ記録します。Blender では、このCSVファイルを読み込み、各オブジェクトの位置と姿勢をキーフレームとして設定することで、シミュレーション結果をアニメーションとして再現します。

```python
st_obj.location = Vector((
    float(row["thr_x"]),
    float(row["thr_y"]),
    float(row["thr_z"]),
))

st_obj.rotation_euler = Euler((
    math.radians(float(row["thr_roll"])),
    math.radians(float(row["thr_pitch"])),
    ST_INIT_ROT.z + (
        math.radians(float(row["thr_yaw"]))
        - math.radians(st0["yaw"])
    ),
), "XYZ")

st_obj.keyframe_insert(data_path="location", frame=frame)
st_obj.keyframe_insert(data_path="rotation_euler", frame=frame)
```
制御装置と吊り荷については、CSV ファイルに記録した XYZ 位置と Roll/Pitch/Yaw を Blender の座標・回転へ反映します。各フレームで `keyframe_insert()` を実行することで、PyBullet で得られた運動を Blender 上のアニメーションとして再構成します。

このアニメーションは結果を可視化するだけでなく、吊り荷の揺れや制御装置との相対的な動きなど、**数値だけでは把握しにくい挙動を目視で確認する**ためにも使用します。
