# はじめに

[前回](https://zenn.dev/rindajones/articles/variable-target-training)は、H鋼を対象として可変目標Yaw制御モデルを学習しました。

最終的に、

```text
-90° ～ +90°
5°刻み
37目標
```

を1つのモデルで学習する `full range` 方式を採用し、全37目標で `physical_success` と `quality_success` を満たすモデルを得ることができました。今回は、この学習方法を、

```text
HSteel
Plate
Truss
```

の3種類の吊り荷へ適用します。

目的は、単に3種類すべてで制御できることを確認するだけではありません。形状や質量の異なる吊り荷に対して同じ学習方法を適用したとき、

> **学習過程や推論時の制御結果に、どのような違いが現れるのか**

を比較します。

今回は学習ログと推論結果を数値で比較し、実際の制御動画については次回紹介します。

# 3種類の吊り荷

今回使用する吊り荷は、[これまでの開発で使用してきたH鋼、平板、トラス](https://zenn.dev/rindajones/articles/a8b6189171848f#吊り荷)の3種類です。

| Payload | Mass | Shape |
| --- | ---: | --- |
| HSteel | 700 kg | 7 m のH鋼 |
| Plate | 1,000 kg | 7 m × 2 m の平板 |
| Truss | 1,200 kg | 長さ10 mのトラス |

3種類とも同じスラスター構成を使用しますが、吊り荷の形状や質量は異なります。

今回の目的は、これらに対して同一の `full range` 学習方法を適用し、その結果を比較することです。

# 学習条件

基本的な学習方法は前回のH鋼と同じです。

目標Yaw角は、

```text
-90°, -85°, -80°, ... , 0°, ... , +80°, +85°, +90°
```

の37目標です。また、目標角を絶対値によって、

```text
small :  0° ～ 20°
mid   : 25° ～ 60°
large : 65° ～ 90°
```

の3つの範囲に分け、学習エピソードとReplay Bufferのサンプリングが特定の角度範囲へ偏らないようにしています。

学習中は `10,000 step` ごとに探索なしのdeterministic evaluationを行い、37目標を個別に評価します。評価では、

```text
physical_success
quality_success
```

に加えて、

```text
最終Yaw誤差
適用指令
Raw指令
目標到達後のhold出力
```

などを確認します。

# 3種類を個別に学習する

今回は、1つのActorで3種類すべての吊り荷を制御するわけではありません。

```text
HSteel → HSteel用Actor
Plate  → Plate用Actor
Truss  → Truss用Actor
```

として、それぞれ独立して学習します。つまり、共通なのは学習方法と制御方針であり、学習されたモデルそのものは吊り荷ごとに異なります。これにより、

> **同じ学習方法を異なる吊り荷へ適用したとき、学習結果がどの程度変わるのか**

を比較できます。

# 学習過程を比較する

まず、3種類の吊り荷について学習過程を比較します。

学習中は `10,000 step` ごとに、-90°～+90°の37目標についてdeterministic evaluationを行っています。

以下は、各評価時点における `quality_success` の成功率です。横軸は学習 `step`、縦軸は37目標に対する成功率を示します。また、破線はそれぞれの吊り荷で採用した `best Actor` の `step` を示しています。

![学習過程](/images/payload-yaw-control/07/quality_success_rate_training_best_steps.png)

:::message
3種類で学習stepの最大値が異なるのは、同じ `step` 数で学習を終了していないためです。deterministic evaluationを確認しながら学習を継続し、これ以上の改善が期待できないと判断した時点で、それぞれ終了しています。
:::

3種類とも学習初期には成功率が上昇しますが、その後は大きく変動しています。高い成功率に到達した後も、その性能が維持されるとは限りません。

この結果からも、

> **学習stepを増やせば、より良いActorが得られるとは限らない**

ことが分かります。


H鋼では `550,000 step` で初めて37目標すべてについて、

```text
physical_success = 1.00
quality_success  = 1.00
```

を達成しました。

一方、平板では `840,000 step` で、

```text
physical_success = 1.00
quality_success  = 0.97
```

となりました。

トラスでは比較的早い段階から高い成功率に到達し、

```text
240,000 step : physical_success = 0.95
               quality_success  = 0.95

260,000 step : physical_success = 0.97
               quality_success  = 0.97
```

となっています。

その後も成功率は変動し、`980,000 step` では、

```text
physical_success = 1.00
quality_success  = 0.97
```

となりました。

このため、最終 `step` の `Actor` をそのまま使用するのではなく、学習中に保存した `best Actor` をそれぞれの吊り荷の推論に使用します。なお、`best Actor` は `quality_success` の成功率だけで決定しているわけではありません。最終Yaw誤差や適用指令、Raw指令、`hold` 出力なども含めて評価しています。


# 代表的な目標角で推論する

それぞれの吊り荷で採用した `best Actor` を使い、

```text
-90°
-45°
0°
+45°
+90°
```

の5つの目標Yaw角について推論を行いました。

ここでは、各推論結果について主に、

```text
最終Yaw絶対誤差
平均適用指令
最大適用指令
```

を確認します。

平均適用指令だけでなく最大適用指令も確認するのは、平均的には低い出力で制御できていても、旋回中に瞬間的な大出力を使用している可能性があるためです。

また、最大適用指令については値だけでなく、推論中のどの時点で使用されたのかも確認します。


## H鋼

まず、H鋼の結果です。

5つの目標Yaw角のうち、+45°と+90°を代表例として、Yaw角とスラスター出力の時間変化を示します。

![目標角45°](/images/payload-yaw-control/07/hsteel_p45.png)

![目標角90°](/images/payload-yaw-control/07/hsteel_p90.png)

続いて、5つすべての目標Yaw角について、最終Yaw絶対誤差、平均適用指令、最大適用指令を比較します。


| Target | Yaw error | Mean applied | Max applied |
| ---: | ---: | ---: | ---: |
| -90° | 3.19° | 0.090 | 0.741 |
| -45° | 4.12° | 0.050 | 0.383 |
| 0° | 0.11° | 0.007 | 0.024 |
| +45° | 4.67° | 0.053 | 0.343 |
| +90° | 3.36° | 0.091 | 0.756 |

:::message
`Mean applied` と `Max applied` は、それぞれ推論中に使用されたスラスターの平均出力と最大出力を示します。値は最大推力を1.0とした正規化値です。
:::

平均適用指令を見ると、±45°では約0.05、±90°では約0.09となっており、目標角の絶対値が大きくなるにつれて必要な出力も大きくなっています。

一方、Yaw誤差は目標角の大きさに比例していません。±90°のYaw誤差が約3°であるのに対して、±45°では4°を超えています。この結果からも、

> **目標角が大きいほど制御が難しいとは限らない**

ことが分かります。

また、±90°では平均適用指令が約0.09である一方、最大適用指令は約0.75まで上昇しています。ただし、この大きな指令は目標到達後の姿勢維持に使用されているわけではありません。+90°の場合、最大適用指令 `0.756` は推論開始から約2.3秒、Payload Yawが約6°の時点で使用されています。

つまりH鋼では、旋回初期に一時的に大きな出力を使用し、その後は出力を下げながら目標角へ近づく制御となっています。

## 平板

次に、平板の結果です。

5つの目標Yaw角のうち、+45°と+90°を代表例として、Yaw角とスラスター出力の時間変化を示します。

![目標角45°](/images/payload-yaw-control/07/plate_p45.png)

![目標角90°](/images/payload-yaw-control/07/plate_p90.png)

続いて、5つすべての目標Yaw角について、最終Yaw絶対誤差、平均適用指令、最大適用指令を比較します。

| Target | Yaw error | Mean applied | Max applied |
| ---: | ---: | ---: | ---: |
| -90° | 0.36° | 0.140 | 0.695 |
| -45° | 3.37° | 0.065 | 0.576 |
| 0° | 4.73° | 0.024 | 0.051 |
| +45° | 1.44° | 0.091 | 0.405 |
| +90° | 1.03° | 0.176 | 0.906 |

平板でも、目標角の絶対値が大きくなるにつれて平均適用指令が大きくなる傾向があります。

特に+90°では平均適用指令が `0.176`、最大適用指令は `0.906` となり、今回の推論結果の中で最も大きな最大出力を使用しています。ただし、この `0.906` が使用されたのは推論開始から約3.3秒、Payload Yawが約10°の時点です。したがって、目標角付近で姿勢を維持するために大出力を使用したのではなく、90°へ向けて旋回する初期段階で使用されています。

Yaw誤差を見ると、-90°では0.36°、+90°では1.03°と小さい一方、0°では4.73°となっています。

H鋼と同様に、平板でも目標角の大きさと最終的なYaw誤差には単純な関係は見られません。

## トラス

最後に、トラスの結果です。

5つの目標Yaw角のうち、+45°と+90°を代表例として、Yaw角とスラスター出力の時間変化を示します。

![目標角45°](/images/payload-yaw-control/07/truss_p45.png)

![目標角90°](/images/payload-yaw-control/07/truss_p90.png)

続いて、5つすべての目標Yaw角について、最終Yaw絶対誤差、平均適用指令、最大適用指令を比較します。

| Target | Yaw error | Mean applied | Max applied |
| ---: | ---: | ---: | ---: |
| -90° | 3.11° | 0.202 | 0.746 |
| -45° | 1.62° | 0.104 | 0.366 |
| 0° | 1.65° | 0.004 | 0.075 |
| +45° | 0.53° | 0.104 | 0.567 |
| +90° | 3.30° | 0.203 | 0.631 |

トラスでも、目標角の絶対値が大きくなるにつれて平均適用指令が増加しています。

±90°では平均適用指令が約0.20となり、H鋼や平板より大きな出力を継続的に使用しています。一方、+90°の最大適用指令は `0.631` で、H鋼の `0.756`、平板の `0.906` より小さくなっています。また、最大適用指令が現れるタイミングにも違いがあります。

H鋼と平板の+90°では、旋回開始から数秒以内に最大出力が使用されていました。これに対してトラスの+90°では、最大適用指令 `0.631` が使用されたのは約13.3秒後で、その時点ですでにPayload Yawは約40°まで旋回しています。

この結果から、トラスでは旋回開始時に瞬間的な大出力を使用するというよりも、

> **比較的大きな出力を継続して使用しながら旋回する**

制御になっていることが分かります。

# 3種類の吊り荷を比較する

ここまでの結果を、3種類の吊り荷で比較します。

5つの代表目標についてYaw絶対誤差を平均すると、

| Payload | Mean Yaw error |
| --- | ---: |
| HSteel | 3.09° |
| Plate | 2.19° |
| Truss | 2.04° |

となりました。

今回の5目標ではトラスの平均Yaw誤差が最も小さくなっています。

一方、平均適用指令を見ると、H鋼、平板、トラスで必要な出力には明確な違いがあります。H鋼は比較的小さな平均出力で旋回し、必要な場面で一時的に大きな出力を使用しています。平板も同様に旋回初期に大きな出力を使用し、特に+90°では最大適用指令が `0.906` まで上昇しました。

これに対してトラスは、瞬間的な最大出力は必ずしも大きくありませんが、旋回中の平均出力はH鋼や平板より大きくなっています。つまり、3種類の吊り荷では、

```text
HSteel : 比較的小さな平均出力 + 必要時に大きな出力
Plate  : HSteelより大きな平均出力 + 旋回初期に大きな出力
Truss  : 比較的大きな出力を継続して使用
```

という違いが見られました。

一方、必要な出力が大きい吊り荷ほどYaw誤差が大きくなるわけではありません。今回の5目標では、平均適用指令が大きいトラスが最も小さな平均Yaw誤差となっています。

このことから、

> **吊り荷によって必要な出力やその使い方は異なるが、それがそのまま制御精度の違いになるわけではない**

ことが分かります。


# 今回のまとめ

今回は、前回構築した `full range` 学習をH鋼、平板、トラスの3種類の吊り荷へ適用しました。

3種類とも、

```text
-90° ～ +90°
5°刻み
37目標
```

を対象として、それぞれ独立したActorを学習しています。

学習過程を比較すると、3種類とも高い成功率に到達した後も性能は変動しており、学習stepを増やせば必ずより良いActorが得られるわけではありませんでした。

また、それぞれの `best Actor` を使って代表的な5目標を推論した結果、目標角の絶対値が大きくなるにつれて必要な出力は増加する一方、Yaw誤差は単純には増加しませんでした。

さらに、出力の使い方にも吊り荷による違いが見られました。H鋼と平板では旋回初期に一時的な大出力を使用するケースが見られたのに対して、トラスでは比較的大きな出力をより長く使用しながら旋回しています。

今回の結果から、

> **同じ学習方法と制御方針を使用しても、吊り荷によって学習過程だけでなく、学習される出力の使い方にも違いが現れる**

ことが確認できました。

次回は、+45°と+90°の推論動画から実際の制御動作を確認します。
さらに、H鋼、平板、トラスの制御結果を比較し、今回の可変目標Yaw制御で得られた結果をまとめます。
